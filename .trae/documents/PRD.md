# 科学游戏开发项目 PRD

## 1. 产品概述

基于开源科研游戏项目进行网页端轻量化二次开发，打造一套可在浏览器运行的科学游戏平台。目标用户为对科学感兴趣的非专业玩家，通过游戏化方式普及科学知识。

项目核心价值：
- 极速上线，复用成熟开源科研游戏代码
- 纯前端静态部署，对接 GitHub Pages
- 可 iframe 嵌入现有官网

## 2. 核心功能模块

### 2.1 游戏模块（按优先级排序）

| 优先级 | 模块名称 | 基于开源项目 | 核心玩法 |
|--------|----------|--------------|----------|
| P0 | 蛋白质折叠解谜 | foldit/foldit | 3D 蛋白结构拖拽折叠、解谜评分 |
| P0 | 相对论沉浸可视化 | MITGameLab/OpenRelativity | 光速运动视觉畸变、时空扭曲 |
| P1 | 极速轻量解谜 Demo | leigest519/OpenGame | AI 生成科学解谜小游戏 |
| P2 | 通用 3D 数据可视化组件 | urchinbrain/urchin | 供全项目复用的 3D 渲染组件 |
| P2 | 逻辑/几何解谜游戏 | nandgame + hyperrogue | 数学逻辑解谜关卡 |

### 2.2 页面结构

1. **游戏主页** (`/`): 展示所有游戏入口，新手引导入口
2. **游戏内页** (`/game/[name]`): 各游戏独立运行页面
3. **数据看板** (`/stats`): 玩家游玩数据统计展示

## 3. 通用功能要求

### 3.1 数据统计
- 前端本地存储：游玩时长、任务完成数、得分/通关记录
- 数据上报接口：同步至官网数据看板页面

### 3.2 接口预留
- NFT 成就调用接口
- 游戏代币奖励调用接口
- 仅定义接口名称与入参，不涉及区块链逻辑

### 3.3 交互适配
- 电脑端：键鼠操作
- 移动端：触屏优化（拖拽、旋转、缩放）
- 简易图文新手引导

## 4. 视觉设计规范

### 4.1 配色方案
| 用途 | 颜色 |
|------|------|
| 主色调 | 深蓝 #1a2a4a |
| 辅助色 | 深空灰 #2d3436 |
| 强调色 | 极光青 #00d4aa |

### 4.2 设计风格
- 科研科技感，分子/粒子/数据流动态特效
- 简洁专业，不做花哨动画
- 统一按钮、弹窗、字体、背景风格

### 4.3 技术规范
- 纯前端 HTML + CSS + JavaScript
- 3D 网页渲染技术（Three.js 等）
- 静态网页，无后端服务、无数据库依赖
- 所有资源路径使用相对路径

## 5. 目录结构

```
game/
├── fold-protein/        # 蛋白质折叠解谜
│   ├── core/           # 原项目核心算法
│   ├── ui/             # 自定义界面
│   ├── api/            # 数据上报接口
│   └── assets/         # 模型/图片资源
├── relativity-view/    # 相对论可视化
│   ├── sim-core/       # 原生物理模拟
│   ├── scene/          # 场景资源
│   ├── task/           # 任务逻辑
│   └── ui/             # 界面代码
├── quick-demo/         # 极速轻量 Demo
├── common/             # 公共组件
│   └── data-view/      # 3D 数据可视化组件
└── extend-puzzle/      # 逻辑/几何解谜
```

## 6. 开源合规要求

1. 每个引用开源代码的文件头部添加中英文溯源注释
2. 标注原项目名称、GitHub 地址、开源协议
3. 仓库根目录新建 `OPEN_SOURCE_RECORD.md` 汇总所有引用

## 7. Git 提交规范

格式：`【模块名称】基于XX开源项目改造 + 核心变更内容`

## 8. 交付标准

1. 完整可运行静态网页文件
2. 资源路径全部使用相对路径
3. 附带中文部署说明（GitHub Pages 部署步骤）
4. 输出文件无编译依赖，下载即可本地运行
